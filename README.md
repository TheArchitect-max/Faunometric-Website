# Faunometric Website

Public GitHub Pages showcase for **Faunometric — Bioacoustic Intelligence Platform**.

This repository is intentionally separate from the private proprietary Faunometric source repository. It contains only public-facing website assets and high-level product information.

## Purpose

This site is a static portfolio and documentation layer for the TheArchitectMax ecosystem. It does not contain the Faunometric production backend, private source code, training data, model weights, internal schemas, secrets, payment processing, authentication, database functionality, or SaaS runtime.

## Public site

Expected GitHub Pages URL:

`https://thearchitect-max.github.io/Faunometric-Website/`

If GitHub Pages is not yet enabled for this repository, configure **Settings → Pages → Deploy from a branch → main / root**. No GitHub Actions workflow is required for this static site.

## Files

- `index.html` — public project showcase
- `assets/styles.css` — responsive chiaroscuro / tenebrism / sfumato visual system
- `assets/site.js` — minimal accessible navigation behavior
- `assets/faunometric-signal.svg` — original conceptual bioacoustic visual
- `favicon.svg` — original project icon
- `404.html` — GitHub Pages fallback page
- `IMAGE_CREDITS.md` — visual provenance and licensing notes
- `robots.txt` — crawler guidance
- `.nojekyll` — serve the repository as plain static files

## Public-information boundary

The site describes what Faunometric is intended to do, why the project exists, the high-level capabilities, project status, and scientific boundaries. It intentionally omits reconstructable implementation details.

The underlying software remains proprietary / All Rights Reserved. Publication of this website repository does not place the underlying Faunometric software under an open-source license.

## Visual assets

No external stock imagery is used. The site visual and favicon are original project-specific SVG assets created for this public showcase. See `IMAGE_CREDITS.md`.

## External services

The site uses no analytics, ads, cookies, external JavaScript CDNs, web fonts, authentication, checkout, payment processing, or external tracking scripts.
